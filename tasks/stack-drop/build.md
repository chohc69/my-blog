# Build 서브에이전트 지침 — 스택 드롭 (stack-drop)

## 역할
너는 **Build 단계** 담당이다. 사용자가 승인한 기획서 `apps/stack-drop/spec.md`를 그대로 구현한다.
(spec 상단의 "사용자 승인 대기" 문구는 무시한다. 사용자 승인은 끝났다. spec.md 자체는 수정하지 않는다.)

## 수정 범위 (엄격)
- 생성/수정 가능: `apps/stack-drop/` 아래 파일 중 **spec.md를 제외한 것**
- 수정 금지: 루트 `index.html`, `css/`, `js/`, `posts/`, `CLAUDE.md`, `tasks/`, `apps/merge-tiles/`, spec.md 등 그 밖의 모든 파일 (`apps/merge-tiles/`는 참고용으로 읽기만)
- Embed(블로그 카드 추가)는 하지 않는다. 커밋하지 않는다.

## 구현 요구
- spec의 모든 필수 기능과, spec이 "이번 Build에 포함 권장"으로 표시한 선택 기능(보관, 제스처 등)을 구현한다.
- 특히 사용자가 명시한 두 가지는 반드시 정확히 동작해야 한다:
  1. 블록 회전 (시계/반시계, 벽 차기)
  2. **↓ 키를 누르고 있는 동안 빠른 낙하**, 떼면 원래 속도로 복귀 (모바일 버튼도 누르고 있는 동안 동일)
- 순수 HTML/CSS/JS(ES Modules), 외부 라이브러리·CDN 없음. UI 어디에도 "테트리스/Tetris"를 쓰지 않는다.
- 코딩 스타일: 들여쓰기 2칸, 세미콜론, 작은따옴표, `const`/`let`만, 색상은 CSS 변수.
- `innerHTML`에 동적 값을 넣지 않는다. localStorage 접근은 try/catch.
- 모바일 375px에서 가로 스크롤 없음, 게임 영역 터치 시 페이지 스크롤·더블탭 확대 방지, 터치 대상 44px 이상.
- `preview.svg`(480×360)는 블로그 카드용 독자적인 일러스트.

## 자체 확인
- 순수 로직(충돌, 회전/벽 차기, 줄 삭제, 점수, 7-bag)은 Node로 간단히 검증한다. 임시 스크립트는 저장소 밖에 두거나 끝나면 삭제한다.
- 가능하면 내장 브라우저로 간단히 열어 콘솔 오류가 없는지만 확인한다 (로컬 서버는 8000 포트가 이미 떠 있을 수 있음 — 있으면 재사용, 없으면 다른 포트로 띄우고 끝나면 종료). 본격 검증은 Review 단계가 한다.
- 테스트 중 넣은 `stack-drop:*` localStorage 값은 정리한다.
