## 요약

**결론: 조건부 통과.**
게임 로직·조작·저장·되돌리기·이어하기·게임 오버·테마·임베드·반응형은 모두 기획서대로 동작합니다.
문제 1건(미획득 메달 배지의 라이트 모드 대비 미달)을 고쳤습니다.
"조건부"인 이유는 스크린리더 실청취, 실기기 터치, `prefers-reduced-motion` 실제 적용을 이 환경에서 확인하지 못했기 때문입니다.

- **브라우저**: 내장 브라우저, `python -m http.server 8000`(저장소 루트), `http://localhost:8000/apps/merge-tiles/`.
  - 확인한 화면(스크린샷): 라이트 기본 화면, 키 입력 직후(슬라이드 애니메이션 도중), 게임 오버 오버레이, 새 게임 확인 대화상자,

## 발견한 문제와 조치

### 1. [수정함] 미획득 메달 배지의 라이트 모드 글자 대비 미달
- 증상: `.medal__badge`에 `opacity: 0.75`가 걸려 있어 muted 글자(#59636e)의 실효 색이 약 #838a92 → 흰 배경 대비 **약 3.5:1**(AA 4.5:1 미달). 다크 모드도 약 4.5:1로 경계선.
- 조치: `apps/merge-tiles/style.css`의 `.medal__badge`에서 `opacity: 0.75`를 제거하고 `.medal.is-earned .medal__badge`의 `opacity: 1`도 정리. 미획득 상태는 기존 점선 테두리 + muted 색 + 배경 없음으로 충분히 구분됨(spec "흐리게(윤곽선만)" 유지).
- 결과: 미획득 배지 대비 라이트 6.11 / 다크 7.22 수준(muted 텍스트 기준). 375px·320px 화면에서 수정 반영 확인.

### 2. [수정 안 함, 경미] 참고 사항
- **되돌리기 배지 숫자**: 게임 시작 직후(되돌릴 수가 없을 때) 버튼은 비활성이지만 배지는 "1"(남은 횟수)을 보여 줌. spec의 "남은 횟수 표시"와 일치하므로 그대로 둠.
- **임베드 테마 우선순위**: 초기 적용은 `?theme` → 저장값 순이지만, `storage` 이벤트에서는 저장값 → `?theme` 순. 같은 오리진 부모가 테마를 바꾸면 iframe이 따라가게 하려는 의도로 보이며 spec 6.3과 맞음. 그대로 둠.
- **게임 오버 시 포커스 스크롤**: `retryButton.focus()`에 `preventScroll`이 없어 작은 화면에서 페이지가 약간 스크롤될 수 있음. 버튼을 보이게 하는 동작이라 유지.
- **오버레이 반투명 배경**: 뒤 타일이 비쳐 보이지만 실측 대비(muted 글자 약 5:1 이상)는 기준 충족.
