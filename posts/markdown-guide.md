이 글은 블로그가 지원하는 마크다운 문법을 모두 보여줍니다.
새 문법을 추가했다면 여기서 렌더링을 확인하세요.

`##`·`###` 제목이 3개 이상이면 글 위에 목차가 자동으로 붙습니다.

## 텍스트 꾸미기

**굵게**, *기울임*, ~~취소선~~, `인라인 코드`를 쓸 수 있습니다.
밑줄로도 쓸 수 있어요: __밑줄 두 개는 굵게__, _밑줄 하나는 기울임_

줄 끝에 백슬래시를 붙이면\
강제로 줄을 바꿀 수 있어요.

링크는 [MDN 문서](https://developer.mozilla.org)처럼 쓰고,
주소만 넣으려면 <https://example.com> 처럼 꺾쇠로 감쌉니다.
주소에 괄호가 들어가도 됩니다: [마크다운 (위키백과)](https://en.wikipedia.org/wiki/Markdown_(disambiguation)).
공백이 있는 주소는 [꺾쇠로 감싼 링크](<https://example.com/a b>)처럼 씁니다.

모든 제목에는 id가 붙어서 `[목록](#목록)`처럼 바로가기 링크를 만들 수 있습니다.
제목에 마우스를 올리면(모바일에서는 항상) 옆에 `#` 링크가 보입니다.

특수문자를 그대로 보여주려면 백슬래시를 붙입니다: \*별표\*, \_밑줄\_

HTML 태그는 실행되지 않고 글자로 보입니다: <script>alert('안전')</script>

>

## 코드

코드 블록 오른쪽 위의 **복사** 버튼을 누르면 코드가 클립보드에 복사됩니다.

```javascript
// 마크다운 파일을 불러와 렌더링하기
async function loadPost(slug) {
  const res = await fetch(`posts/${slug}.md`);
  const text = await res.text();
  return parseMarkdown(text);
}
```

```css
:root[data-theme="dark"] {
  --color-bg: #0f1115;
  --color-text: #d4d8de;
}
```

긴 코드는 가로로 스크롤됩니다:

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory ./my-blog  # 아주 긴 주석이 붙어서 한 줄이 화면보다 길어지는 경우
```
